# GTA VI Twitch CCU forecast

The model uses the UTC hour-1 print as its scale and empirical log-ratio quantiles by hour. A comparable is included exactly when its name is not the GTA VI category and the lowercase combined `unlock + platforms` text contains `rolling` or `midnight local`. This intentionally includes PC titles when their launch notes meet that rule; it does not impose a PC or "unverified" exclusion.

LOO evaluation on the rolling-filtered comparable launches, using the actual `forecasts()` function from `main.py`, scored **0.330360** mean pinball loss versus **0.356804** for persistence on the same **276** launch-hour pairs. The independent workdir evaluator's shrink sweep was 0.3304 (0), 0.3313 (0.15), 0.3393 (0.3), and 0.3630 (0.5), so no shrink is applied. Using every launch type scored 0.7139 in the separate broad-filter LOO evaluation. The set is small and heterogeneous, so these scores are evidence for the filter rather than a guarantee for GTA VI.

Across the comparables, the median viewer ratio to hour 1 is about 0.87 at hour 2, 0.73–0.93 through the UTC morning, and 2.0–2.4 in the evening. The p90 grows from 1.28 at hour 2 to tens or hundreds in daytime/evening, so quantiles use the empirical spread. The GTA VI pre-release series has a 24-hour median of 1,553 viewers at its last checkpoint, with recent spikes; it does not directly set launch magnitude. In practice, hour 1 was 1.3–1.6 times each launch's recent 24-hour median, while known channels/viewers ranged from 0.010 to 0.027. Four practice cases are too few to justify a fitted trend or channels correction.

Local validation: p00–p03 each emitted 23 ordered, valid quantiles; two model runs were byte-identical and differed from the starter baseline. Model runs took 0.17–0.23 seconds total for four cases; the median evening q50 was 1.991 times p1. Empty-history/comparable cases at p1=1 and p1=5,000,000 also emit valid forecasts. The program uses only Python's standard library and embeds no external calibration files.
